# Face Recognition Attendance System

An AI-based attendance system that automatically marks 
attendance using real-time face recognition.

## Features
- Real-time face detection and recognition
- Automatic attendance marking in CSV file
- Support for multiple students

## Tech Stack
- Python
- OpenCV
- face_recognition library

## How to Run
1. Clone the repository
2. Install dependencies: pip install -r requirements.txt
3. Add student photos in Dataset folder
4. Run: python src/encode_faces.py
5. Run: python src/attendance_system.py
